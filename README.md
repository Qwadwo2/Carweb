# Carweb
# Manu Rentals — Static Demo

Simple static site demo for a car rental landing page.

Preview
- Open [index.html](index.html) in a browser, or serve with a static server:
  - Python: `python -m http.server 8000`
  - Node: `npx http-server . -p 8000`

What’s included
- [index.html](index.html) — main page
- [styles.css](styles.css) — styling
- [script.js](script.js) — interactive behaviour (functions: `renderCars`, `populateSelect`, `filterCars`, `quickSelect`, `setMinDates`, `calcDays`, `currentCar`, `updatePrice`, `validateField`)
